RöXtimizer

NOTE!
  1. Keep your F. PEN above the target's DEF and your Final P/M DMG Bns above DMG Red, as this tool can't handle negative values.
  2. Make sure the Divinity, Card, Companion & Enchantment you're using match the offensive stats you have in-game, and that they're available here.
  3. Don't swap these out after entering your stats, as this tool won't update stat changes in real time like the game does.
  4. Always double-check the result (2nd slide) to make sure it matches yours.
  5. If you add buffs after setting your cards, the final stats will already have those buffs included.
How to Use
1.Replicates the in-game divinity screen with some adjustments. Tap any slot to open its panel.
2.The 3 dots above the title let you set your div quality, and flash! ez multiple sepir & riper flash here!
3.Top right arrows switch slots. Bottom left arrows switch between divinities in the same slot.
4.You can add up to 8 divinities per slot with + Add Div. Hit Use to mark which one's currently in use.
5.All divs added here will be used by the optimizer to find the most effective slot combination.
6.Lock a div to protect it from being deleted or replaced by the optimizer.
7.This tool only supports some main-offensive stats. Stat%, HP%, ATK%, and Haste aren't included! So yeah, it might not be accurate for ED ED ED / SB SB SB enjoyers!
